WhisperBase и LlamaBase подчиняются одному паттерну

```Python
class Model:
```

`Оба интерфейса живут в строгом согласовании с Java логикой, так что видоизменять их не стоит, они не синхронизированы, просто описаны одинаково`

Transcription и TranscriptionRepository это интерфейсы созданные для взаимодействия с базой данных из python модуля, примеры работы приведены ниже

### Конфигурационные атрибуты классов

#### WhisperBase:

- `language` — `str` — язык распознаваемой речи. По умолчанию `"ru"` — русский.
    
- `threads` — `int` — количество потоков процессора, используемых для распознавания.
    
- `beam_size` — `int` — ширина поиска Beam Search. Чем больше значение, тем тщательнее поиск наиболее вероятного результата, но тем выше вычислительная нагрузка.
    
- `best_of` — `int` — количество вариантов распознавания, рассматриваемых при выборке. Большее значение может повысить качество, но увеличить время обработки.
    
- `temperature` — `float` — температура генерации токенов. Значение `0.0` соответствует детерминированному режиму распознавания.
    
- `temperature_increment` — `float` — шаг повышения температуры при повторных попытках распознавания, если предыдущая попытка оказалась неудачной.
    
- `translate` — `bool` — определяет, нужно ли переводить распознанную речь на английский язык вместо транскрибирования на исходном языке.
    
- `timestamps` — `bool` — включает или отключает временные метки для распознанных сегментов речи.
    
- `no_context` — `bool` — запрещает использовать предыдущий текст распознавания в качестве контекста для последующих сегментов. Может уменьшить влияние предыдущих фрагментов на новые.

#### LlamaBase

- `context_size` — `int` — размер контекстного окна модели. Определяет максимальное количество токенов, которое модель может учитывать при обработке запроса и генерации ответа.
    
- `threads` — `int` — количество потоков процессора, используемых для вычислений.
    
- `batch_size` — `int` — максимальное количество токенов, обрабатываемых за один пакет при обработке входного текста. Влияет на скорость обработки и потребление оперативной памяти.
    
- `micro_batch_size` — `int` — размер микропакета, на который разбивается основной пакет при вычислениях. Позволяет управлять нагрузкой на оперативную память.
    
- `max_tokens` — `int` — максимальное количество новых токенов, которые модель может сгенерировать в ответе.
    
- `temperature` — `float` — регулирует случайность генерации. Низкие значения делают ответы более предсказуемыми, высокие — более разнообразными. Значение `0.0` соответствует детерминированной генерации при использовании соответствующего алгоритма выборки.
    
- `topK` — `int` — ограничивает выбор следующего токена заданным количеством наиболее вероятных вариантов. Меньшее значение делает генерацию более предсказуемой.
    
- `topP` — `float` — ограничивает выбор токенов совокупной вероятностью. Например, `0.8` означает, что для выбора используются наиболее вероятные токены, суммарная вероятность которых достигает 80%.
    
- `system_prompt` — `str` — системная инструкция, задающая роль модели, стиль общения, правила поведения и общие требования к ответам.

## Использование интерфейсов
### Примеры:

```Python
from base.interface import whisper

#WhisperBase

def transcribe(model_path: str, audio_path: str) -> dict:

	model = whisper.WhisperBase(model_path)
	
	#Прогружаем модель в память мобильного устройства
	model.initialize()
	
	result = model.transcribe(audio_path)
	
	#Выгружаем модель из памяти мобильного устройства
	model.release()
	
	return result

```

```Python
from base.interface import llama

#LlamaBase

def generate(model_path: str, prompt: str) -> str:

	model = whisper.LlamaBase(model_path)
	
	#Прогружаем модель в память мобильного устройства
	model.initialize()
	
	result = model.generate(prompt)
	
	#Выгружаем модель из памяти мобильного устройства
	model.release()
	
	return result

```

```Python
from base.interface import transcription

#Transcription и TranscriptionRepository

def create_transcription(audio_path, content):

	#Создаем класс репозитория который реализует взаимодействия с базой данных
    transcription_repo = transcription.TranscriptionRepository()

	#Создаем обьект который используется репозиторием
    transcription_obj = transcription.Transcription(audio_path, content)

	#Реализуем транзакцию в базу данных и возвращаем результат
    return transcription_repo.insert(transcription_obj)

```
